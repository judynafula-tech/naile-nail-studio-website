# NAILÉ – The Art of Beautiful Nails

NAILÉ is a modern, elegant website created for a nail studio. It showcases nail services, pricing, designs and appointment options, allowing customers to explore the services and make booking requests through WhatsApp.

## About the Project

The website was designed with a luxury and feminine aesthetic, using a combination of cream, beige, brown and gold colours.

## Features

- Responsive design for desktop and mobile devices.
- Homepage introducing the NAILÉ brand.
- About section.
- Nail services and pricing.
- Gallery showcasing nail designs.
- Gallery image filters and image enlargement.
- Frequently Asked Questions section.
- Booking form with input validation.
- Appointment options for in-person appointments and house calls.
- WhatsApp booking integration.
- Contact information.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Running the Project Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
